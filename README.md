# Quiet Notes Test · 테스트 전용

기존 [Quiet Notes 배포본](https://github.com/zxvniqi/quiet-notes)과 분리한 테스트 확장입니다. 확인 후 승인받기 전에는 기존 저장소에 반영하지 않습니다.

## 설치

기존 Quiet Notes를 확장 관리에서 비활성화한 뒤 아래 주소로 설치하고 새로고침합니다. 두 버전을 동시에 켜지 마세요. 테스트 버전은 별도의 브라우저 설정 저장소를 사용합니다.

```text
https://github.com/zxvniqi/quiet-notes-test
```

마법봉 → **일코 모드 켜기**. 종료는 상단 **보기 → 일코 모드 끄기**입니다. 단축키는 `Ctrl+Shift+M`입니다.

## 2.6.0-beta.2

- 일코 ON에서만 작업 로딩 아이콘을 문서 모양으로 표시하고 화면 정중앙에 배치합니다. 첫 시작 로딩의 터묵스 설정과는 별개이며 이번 수정에는 터묵스 명령을 다시 실행할 필요가 없습니다.
- 상단의 일코 ON 버튼을 보기 메뉴 안으로 이동했습니다.
- 프사를 숨길 때 유저·캐릭터의 바깥 틀과 가로 여백까지 접습니다. 이미지·임베드만 들어 있는 고정 높이 영역도 함께 접으며 iframe을 삭제하거나 재생성하지 않습니다.
- 전자책 모드는 다른 표시 옵션과 관계없이 프사·이미지·에셋·임베드·이름·메시지 번호·메타정보를 숨기고 본문 사이에 얇은 선만 남깁니다. 끄면 이전 보기 옵션을 복원합니다.
- 전자책 상단은 **서재 / 목차 / 메모 / Aa**로 표시합니다. 목차는 상단 도구, 메모는 입력 바를 열고 닫습니다. 전자책의 상하단 접힘 설정은 일반 일코 모드와 별개입니다.
- 전자책의 상단바·입력 바·알림을 종이색으로 통일했습니다. **Aa → 전자책 편집 도구 표시**를 켜면 수정·번역·스와이프 등을 사용할 수 있습니다. 편집 중인 저장·취소 버튼은 항상 유지합니다.
- 실제 SillyTavern 1.19.0 환경에서 발견한 고정 바 위치 밀림과 성능 확장 사용 시 메시지 높이 축소를 수정했습니다. 전자책에서는 챗로비 바로가기와 모델 정보 배지도 숨깁니다.
- 작업 버튼을 펼쳐도 `···`가 남습니다. 바깥을 누르거나 Escape를 누르면 접힙니다.

기존 테마 파일, 대화 내용, 초안, API 설정은 수정하지 않습니다. QR은 기존 테마와 확장의 동작을 유지합니다. 블루레몬에이드가 켜져 있으면 일코 ON 동안 그 화면 스타일을 잠시 내리고 OFF에서 복원합니다.

외부 요청이나 폴링은 없으며, 대화에 새로 삽입된 이미지·임베드 영역만 관찰합니다. 본문 텍스트가 생성될 때마다 전체 대화를 다시 훑지 않습니다.

## 확인 범위

시네마노트 CSS와 실리 메시지/로딩 DOM 구조를 사용한 모바일 390×844, PC 1280×900 회귀 검사 35개 통과. 중앙 정렬, 즉시 숨김, 새 임베드, 설정 복원, 초안 보존, 버튼 핸들러, 1,000회 본문 갱신을 검사했습니다. 제3자 확장의 임의 HTML까지 모두 숨김을 보장하지는 않습니다.

## 기존 버전으로 돌아가기

테스트 확장을 끄고 기존 Quiet Notes를 다시 켠 뒤 새로고침합니다. 테스트 설정은 기존 배포본의 설정과 분리되어 있습니다.

참고한 테마: 블루레몬에이드, 모노하트. 시네마노트는 호환 검증에 사용했습니다.
