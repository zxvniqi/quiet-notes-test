# Quiet Notes Test · 테스트 전용

기존 [Quiet Notes 배포본](https://github.com/zxvniqi/quiet-notes)과 분리한 테스트 확장입니다. 확인 후 승인받기 전에는 기존 저장소에 반영하지 않습니다.

## 설치

기존 Quiet Notes를 확장 관리에서 비활성화한 뒤 아래 주소로 설치하고 새로고침합니다. 두 버전을 동시에 켜지 마세요. 테스트 버전은 별도의 브라우저 설정 저장소를 사용합니다.

```text
https://github.com/zxvniqi/quiet-notes-test
```

마법봉 → **Quiet Notes** → **일코 모드 켜기**. 끌 때도 같은 곳에서 끕니다. 단축키는 `Ctrl+Shift+M`입니다.

## 2.9.0-beta.1

- 전자책 모드의 상단을 자체 읽기 도구로 바꿨습니다. 위쪽 선을 끌어 내리면 **‹ 책장 · 제목 · 검색 · 목차 · Aa** 바가 나옵니다. 기존 상단바와 Chat Top Bar는 보이지 않으며, 그 기능은 **목차** 목록(기록, 새 노트, 제목 바꾸기, 덮기, 삭제, 작성 도구, 연결, 서식, 사전, 환경 설정, 배경, 확장, 프로필, 책장)에서 엽니다.
- 전자책 모드의 입력 바를 메모 칸 모양으로 바꿨습니다. 버튼의 크기와 위치는 테마 그대로입니다.
- 일반 일코 모드의 상단바와 Chat Top Bar가 테마의 버튼 크기와 높이를 그대로 씁니다.

## 2.8.0-beta.1

- 맨 위의 확장 바를 없앴습니다. 대화 위아래의 얇은 선을 끌어서 상단 도구와 입력 바를 엽니다. 위쪽 선은 아래로 끌면 열리고 위로 끌면 닫힙니다. 아래쪽 선은 그 반대입니다.
- 마법봉 메뉴의 **Quiet Notes**를 누르면 **일코 모드 켜기/끄기**와 **설정** 중에서 고릅니다. 보기 옵션과 꾸미기는 모두 설정 창에 있습니다. 확장 탭에서도 같은 설정을 쓸 수 있습니다.
- 글꼴·글자 크기·줄 간격을 기본으로는 건드리지 않습니다. 테마와 Font Manager 설정이 그대로 적용됩니다. 바꾸고 싶으면 설정에서 글꼴을 고르거나 **글자 크기·줄 간격 직접 지정**을 켭니다.
- 전자책 모드는 본문만 남깁니다. 스크롤 막대와 메시지 아래 확장 버튼을 숨기고, 문단 첫 줄을 들여 쓰며, 오른쪽 아래에 읽은 위치(%)만 표시합니다.
- 브라우저에 이전 스타일이 남아 있으면 새 버전으로 다시 불러옵니다.

## 2.7.0-beta.1

- 확장 탭의 **Quiet Notes Test** 항목에서 꾸미기 설정을 바꿀 수 있습니다. 탭 제목, 이름 표시 문구, 알림 위치, 일반 일코의 색·글자 크기·줄 간격·구분선, 전자책의 종이 색·글자 크기·줄 간격·문단 간격·좌우 여백·정렬·구분선을 고를 수 있습니다. 설정은 이 기기에만 저장됩니다.
- 일반 일코 모드도 상단 도구를 `···` 안에 접습니다.
- 전자책 글자 크기와 줄 간격을 줄이고(기본 15px · 1.7), 한글 단어가 줄 끝에서 끊기지 않게 했습니다.
- 확장이 글꼴을 지정하지 않습니다. 테마 글꼴을 그대로 씁니다.
- 전자책에서 상단 도구·Chat Top Bar·입력 바 아이콘을 읽기 앱 모양으로 바꿨습니다. Chat Top Bar의 채팅 이름은 가립니다. 생성 중 정지 버튼도 같은 모양으로 바꿨습니다.
- 입력 바 아이콘의 크기와 위치는 테마 설정을 그대로 씁니다. 전개지시M 창이 보이지 않던 문제를 고쳤습니다.
- 알림을 두 모드 모두 색 띠와 제목 색으로 구분되는 카드로 바꿨습니다.
- 구분선을 더 진하게 하고, 선·짧은 선·별표 중에서 고를 수 있게 했습니다.
- 테마를 바꾸면 대화가 상단바 밑으로 올라가던 문제를 고쳤습니다.
- 상단바가 화면 전체를 덮는 확장 창과 메뉴의 위쪽을 가리던 문제를 고쳤습니다.

## 2.6.0-beta.3

- 전자책 상단바에서 '서재' 글자를 없애고, 왼쪽에 작은 읽기 진행률(%)과 오른쪽 `···`만 둡니다. `···`를 누르면 목차 · 메모 · Aa가 펼쳐지고, 바깥을 누르거나 Escape를 누르면 다시 접힙니다. 상단바 높이를 40px로 줄였습니다.
- 전자책에서 Chat Top Bar를 종이색 한 줄로 바꿨습니다. 입력칸 박스 대신 밑줄, 세리프 글꼴, 옅은 아이콘을 씁니다.
- 전자책에서 QR 버튼을 얇은 테두리의 종이 칩 모양으로 바꿨습니다. QR 배치·분류·동작은 그대로입니다. 입력 바와 목차 아이콘도 같은 톤으로 맞췄습니다.
- 전자책 본문 글꼴이 테마 글꼴에 덮이지 않도록 세리프로 고정했습니다.
- 입력창 아이콘(기본·확장 버튼)을 같은 크기로 맞추고 간격을 줄여 입력칸 자리를 넓혔습니다. 숨겨진 버튼(중지·계속 등)은 그대로 숨김입니다.
- 맨 마지막 메시지 아래에는 구분선을 표시하지 않습니다. 일반 일코 모드도 같습니다.
## 2.6.0-beta.2

- 일코 ON에서만 작업 로딩 아이콘을 문서 모양으로 표시하고 화면 정중앙에 배치합니다. 첫 시작 로딩의 터묵스 설정과는 별개이며 이번 수정에는 터묵스 명령을 다시 실행할 필요가 없습니다.
- 상단의 일코 ON 버튼을 보기 메뉴 안으로 이동했습니다.
- 프사를 숨길 때 유저·캐릭터의 바깥 틀과 가로 여백까지 접습니다. 이미지·임베드만 들어 있는 고정 높이 영역도 함께 접으며 iframe을 삭제하거나 재생성하지 않습니다.
- 전자책 모드는 다른 표시 옵션과 관계없이 프사·이미지·에셋·임베드·이름·메시지 번호·메타정보를 숨기고 본문 사이에 얇은 선만 남깁니다. 끄면 이전 보기 옵션을 복원합니다.
- 전자책 상단은 **서재 / 목차 / 메모 / Aa**로 표시합니다. 목차는 상단 도구, 메모는 입력 바를 열고 닫습니다. 전자책의 상하단 접힘 설정은 일반 일코 모드와 별개입니다.
- 전자책의 상단바·입력 바·알림을 종이색으로 통일했습니다. **Aa → 전자책 편집 도구 표시**를 켜면 수정·번역·스와이프 등을 사용할 수 있습니다. 편집 중인 저장·취소 버튼은 항상 유지합니다.
- 실제 SillyTavern 1.19.0 환경에서 발견한 고정 바 위치 밀림과 성능 확장 사용 시 메시지 높이 축소를 수정했습니다. 전자책에서는 챗로비 바로가기와 모델 정보 배지도 숨깁니다.
- 작업 버튼을 펼쳐도 `···`가 남습니다. 바깥을 누르거나 Escape를 누르면 접힙니다.

기존 테마 파일, 대화 내용, 초안, API 설정은 수정하지 않습니다. QR은 기존 테마와 확장의 동작을 유지합니다. 블루레몬에이드가 켜져 있으면 일코 ON 동안 그 화면 스타일을 잠시 내리고 OFF에서 복원합니다.

외부 요청이나 폴링은 없으며, 대화에 새로 삽입된 이미지·임베드 영역만 관찰합니다. 본문 텍스트가 생성될 때마다 전체 대화를 다시 훑지 않습니다.

## 확인 범위

시네마노트 CSS와 실리 메시지/로딩 DOM 구조를 사용한 모바일 390×844, PC 1280×900 회귀 검사 35개 통과. 중앙 정렬, 즉시 숨김, 새 임베드, 설정 복원, 초안 보존, 버튼 핸들러, 1,000회 본문 갱신을 검사했습니다. 제3자 확장의 임의 HTML까지 모두 숨김을 보장하지는 않습니다.

## 기존 버전으로 돌아가기

테스트 확장을 끄고 기존 Quiet Notes를 다시 켠 뒤 새로고침합니다. 테스트 설정은 기존 배포본의 설정과 분리되어 있습니다.

참고한 테마: 블루레몬에이드, 모노하트. 시네마노트는 호환 검증에 사용했습니다.
